# ПГАС — БрГУ

Электронная подача заявлений на повышенную государственную академическую стипендию в **ФГБОУ ВО «Братский государственный университет»**.

Демо: [https://demo.pgas-demo-site.online](https://demo.pgas-demo-site.online) · API: `https://api.pgas-demo-site.online/api`

## Запуск локально

```bash
cd pgas-system
npm install
npm run backend:install
```

Настройте `backend/.env` (см. `backend/.env.example`), затем:

```bash
cd backend
npx prisma migrate deploy
npm run prisma:seed
npm run dev
```

В другом терминале:

```bash
npm run dev
```

Подробнее: `RUN_ON_NEW_PC.md`, деплой: `server_tutorial.md`, **CI/CD: [`docs/CICD.md`](docs/CICD.md)**, Docker: [`docs/DOCKER.md`](docs/DOCKER.md).

## Роли

**Студент** — заполняет достижения в таблице (черновик), прикладывает файлы, подаёт **одно заявление за период** (зимняя или летняя сессия), следит за статусом и рейтингом.

**Комиссия** — регламент (включая уровни мероприятий и сроки), направления, рассмотрение достижений, правки с шаблонами, экспорт ведомости (XLSX / PDF / Word), архив.

**Администратор** — пользователи, факультеты, группы, подсказки, аудит. Без доступа к регламенту, направлениям и рассмотрению заявлений.

## Периоды подачи

Два конкурсных периода в учебном году: после **зимней** и **летней** сессии. Сроки задаются в регламенте и хранятся в БД. Опционально жёсткий дедлайн через `SUBMISSION_DEADLINE_ISO` в `backend/.env`.

## Правила

- Минимум **25 баллов** (сумма одобренных достижений) для участия в рейтинге; после завершения проверки заявления ниже порога отклоняются.
- Описание достижения — не менее **100 символов** (проверка на клиенте и сервере).
- Вложения: до **10 файлов**, каждый до **2 МБ** (PDF, JPEG, PNG, WebP).

## Сессия

JWT хранится в `localStorage` (`pgas_api_token`, `pgas_session_api`) — стандартная схема для SPA. Права комиссии подтягиваются с сервера при каждом запросе.

## Сброс локальных данных

```js
Object.keys(localStorage).filter(k => k.startsWith('pgas_')).forEach(k => localStorage.removeItem(k));
location.reload();
```
